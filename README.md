# aikido-club-website
Planning, design documentation, and custom code for a WordPress.com website built for a local Aikido club

## Overview
A WordPress.com website built for a local Aikido club. This repository documents the planning, design decisions, and any custom code used throughout the project.

## 🎉 Website Launch
The **Swansea Bay Aikido Club** website is now officially live.

🔗 **Live site:** https://swanseabayaikido.co.uk

This marks the completion of the initial build phase, including content structure, page layout, and overall site setup on WordPress.com.

## Goals
- Improve online presence for the club to attract new members  
- Provide clear information for new and existing students  
- Showcase club news, class information, instructors, and club ethos  

## Tech Stack
- WordPress.com  
- *(Planned)* Custom CSS for future enhancements  

### Development Environment
Although I normally work on **Linux**, this project is currently developed on **Windows 11** using **Visual Studio Code**.  
This reflects my ability to work comfortably across different operating systems.
